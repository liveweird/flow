# flow — web frontend

Vite + React 19 + TypeScript SPA for the Flow app (a developer-intelligence tool for a
~70-developer SaaS unit; currently the v0.1.0 foundation — sign-in, users, teams, feature flags,
i18n, theming — with no Jira/GitLab data yet). UI is [Mantine](https://mantine.dev), routing is
React Router, server state is TanStack Query, and the UI is bilingual (English/Polish) via
react-i18next.

This is a standalone npm workspace — the Gradle build never touches it, and vice versa. Frontend
conventions (API client, i18n rules, theming, coverage gates) are documented in
[CLAUDE.md](CLAUDE.md) in this directory.

## Setup

```
npm install --legacy-peer-deps
```

`--legacy-peer-deps` is required: `openapi-typescript` declares a TypeScript `^5` peer while this
project uses TS 6 (the generated output is compatible).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server on :5176; proxies `/api` → `http://localhost:8084` |
| `npm run build` | Type-check + production build to `dist/` |
| `npm run test` | Run vitest once |
| `npm run test:watch` | Run vitest in watch mode |
| `npm run test:coverage` | Tests with coverage (thresholds enforced in `vite.config.ts`) |
| `npm run lint` | ESLint (sonarjs + complexity backstops, zero-findings gate) |
| `npm run knip` | Dead-code gate (unused files/exports/dependencies) |
| `npm run gen:api` | Regenerate `src/api/schema.ts` from the server's OpenAPI spec |

For local development the backend must be running (`docker compose up postgres` +
`./gradlew :server:run` from the repo root — Ktor listens on :8084).

## API types

`src/api/schema.ts` is generated by `npm run gen:api` from
`../server/src/main/resources/openapi/documentation.yaml` (no running server needed). Run it
after any OpenAPI spec change and commit the result. The typed fetch layer around it is
hand-written in `src/api/` (`http.ts` transport + per-area wrapper modules) — extend that when
adding endpoints; don't introduce a client generator.
